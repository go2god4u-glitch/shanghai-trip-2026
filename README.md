# 상하이 2박 3일 · 2026

2026년 9월 23~25일 상하이 여행을 위한 모바일 우선 오프라인 가이드입니다.

## 사용

- 배포 URL을 출국 전에 한 번 열어 캐시합니다.
- 브라우저 메뉴에서 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
- 화면 코드와 글꼴은 외부 CDN에 의존하지 않습니다. 지도 타일은 고덕지도에서 불러옵니다.
- 오늘·내일 날씨는 온라인일 때 Open-Meteo 예보를 새로 조회하며, 실패하면 지난 예보를 현재 날씨로 표시하지 않습니다.
- 실시간 지도와 날씨에는 인터넷 연결이 필요합니다.
- 장소 이름과 중국어 주소는 탭해서 복사할 수 있습니다.
- 체크리스트 상태는 기기 안에만 저장됩니다.

## 로컬 확인

정적 파일이므로 아무 HTTP 서버에서 열면 됩니다. 서비스 워커는 `file://`에서는 작동하지 않습니다.

```powershell
npx --yes serve .
```
